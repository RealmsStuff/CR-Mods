# Sandbox Extras

A small Sandbox arena for Samantha (`saintpeverell.samantha`, installed with it). Press Use at the switch and she walks in from the far east end. There are no normal waves.

It is a separate pack because a stage whose spawner names an enemy from a pack that is not installed is a mod error, so the main `saintpeverell.sandbox` stage cannot carry this switch as an optional one.

Pip's stage ("Sandbox: Pip") is left out of this release until Pip's pack is published.
