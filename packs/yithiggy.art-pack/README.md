# YiThiggy Art Pack

A collection of 21 graphical hairstyles and three animal-ear accessories by YiThiggy. Every item is unlocked by default and uses Core attachment points so it remains compatible with the 2.1.2 mod baseline. Hairstyles appear under Hair; Cat Ears, Fox Ears, and Bear Ears appear under Hat and inherit the Core Bunny Ears behavior.

The source PNGs use the Core 64 by 64 player canvas. They are kept at their authored size without smoothing or rescaling.
